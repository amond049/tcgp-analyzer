This is a quick side project of mine that I've been thinking about for a while. I want to be able to analyze my performance in Pokemon TCGP but since I know how to code I wanted to make my own analysis tool. This script will allow me to retrieve all of the information for all of the cards currently in the game. Unfortunately, at the time of creating this there is no easy API to call to retrieve all of the information, so I was going to try and cast an attempt of my own. This will need. to be manually run whenever a new pack comes out, but such is the joy of creating my own API.
